# Руководство по сдаче ЛР №6 (Pub/Sub) — порядок показа

Все сценарии запускаются **из меню клиента**, без флагов командной строки и без перезапуска клиента.

## Подготовка (один раз)

```bash
docker compose up -d           # PostgreSQL
dotnet run --project Server    # терминал 1: сервер, журнал публикации и доставки — на экран
dotnet run --project Client    # терминал 2: меню клиента
```

Меню клиента (Pub/Sub)

| Пункт | Действие                                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2 / 3 / 4  | Создать / отменить / оплатить заказ → события OrderCreated / OrderCancelled / PaymentCompleted                           |
| 16         | Состояние Broker, подписчиков, счетчики доставки, dead letter                                                            |
| 17         | Отказ или восстановление подписчика (ввести имя, д/н)                                                             |
| 18         | Отказ или восстановление Broker (Broker-1 / Broker-2, д/н)                                                                           |
| 19         | Подключить новый Subscriber (AnalyticsService)                                                                                                |
| 20         | Повторная доставка dead letter (ввести имя подписчика)                                                                   |
| 21         | Основной сценарий: несколько подписчиков, отказ, новый подписчик, повторная доставка |
| 22         | Повторная доставка: Attempt 1 FAIL, 2 FAIL, 3 SUCCESS                                                                                       |
| 23         | Два Broker: failover                                                                                                                                      |
| 24         | Три клиента одновременно                                                                                                               |
| 25         | Анализ задержек (таблица очередь / обработка / всего)                                                              |
