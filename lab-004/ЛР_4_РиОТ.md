Таблица 3 — Сравнение: без транзакции и с транзакцией

| Критерий                                               | Без транзакции                                                                                        | С транзакцией                                                     |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| Несколько связанных операций         | выполняются независимо, каждая фиксируется сразу (автокоммит) | выполняются как единое целое (BEGIN … COMMIT)       |
| Атомарность                                         | отсутствует                                                                                             | есть — «всё или ничего»                                    |
| Возможность частичного изменения | **да** (эксперимент 2: заказ без списания остатка)                       | **нет** (эксперименты 3 и 4)                            |
| Использование COMMIT                              | не используется — изменения фиксируются неявно                            | подтверждает все изменения (эксперимент 3) |
| Использование ROLLBACK                            | невозможен — изменения уже сохранены                                               | отменяет все изменения (эксперимент 4)         |
| Сохранение изменений при успехе    | да                                                                                                               | да, после COMMIT                                                       |
| Отмена изменений при ошибке            | нет                                                                                                             | да, через ROLLBACK                                                     |
| Согласованность результата            | нарушается (в БД появляется заказ, которого нет в остатке)          | сохраняется                                                        |
